# Archive

Completed or retired plans and trackers, preserved in dated snapshots:

```text
docs/archive/<YYYY-MM-DD>/
  README.md        why this snapshot was taken and what each file covered
  plans/           the retired plans
  tracking/        their trackers
```

Archive a plan when it is complete or superseded, after promoting its durable
decisions into concepts, implementation guides, or
[provenance](../papers/provenance.md). The snapshot README names each file,
says in one line what it records, and points to where its conclusions now
live. Links inside archived documents keep their pre-archive targets; do not
rewrite them.

Archived documents are records, not guidance. Nothing maintained cites them as
the source of a rule.
