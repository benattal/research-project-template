# Papers

This directory holds the paper-facing material of the project:

- local copies of cited references (this page), so design and review
  discussions can cite stable page and section numbers without network
  access;
- [research provenance](provenance.md), the implementation decisions that
  remain binding after the investigations that produced them were archived;
- `submission/`, the submitted paper's review cycle: reviews, rebuttal, and
  revision record. These files are frozen on purpose (see
  [writing style](../style/writing.md)).

## Local references
