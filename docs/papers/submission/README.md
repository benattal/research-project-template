# Submission record

The paper's review cycle, kept as submitted: the reviews, the rebuttal, and a
revision record of what changed between versions and why. These documents are
frozen once sent. Quoting a reviewer's objection and answering it, or stating
what a submitted version got wrong, is their content (see
[writing style](../../style/writing.md)).

Suggested files, added as the cycle proceeds:

- `reviews.txt`: the reviews as received;
- `rebuttal.md`: the response as sent;
- `revision.txt`: the change record of the camera-ready or resubmission.
